# Prakhar Saraswat — Backend Engineering Portfolio

A responsive portfolio for Prakhar Saraswat, built with HTML, CSS, JavaScript and local SVG artwork. Showcases Java / Spring Boot work at TCS, TNREGINET contributions, PostgreSQL, integrations, and technical leadership.

## Preview locally

Run `python3 -m http.server 4173` from this repository, then open `http://localhost:4173`.

## GitHub Pages

In repository Settings → Pages, set Source to **Deploy from a branch**, choose **main** and **/(root)**, then Save. The project address is `https://prasw23.github.io/-Portfolio/` once GitHub confirms deployment.

## Edit

- `index.html`: profile, experience and contact links.
- `script.js`: project case studies, skills and UI interactions.
- `styles.css`: responsive layout, colors and light / dark themes.
- `resume.html`: printable résumé with browser Save as PDF.
- `assets/favicon.svg`: local brand icon.

No build tools, server, external scripts, analytics or paid dependencies are required. Links are relative so the site works under the repository's Pages subpath.

Profile content is based on the latest provided résumé, dated November 7, 2026. Contributions are described as team-delivered work without fabricated metrics or confidential client code.
